# Chatbot'tan Takım Arkadaşına

Yapay zekâ ajanları üzerine bir sunum: yapay zekâ nereden geldi, bir dil modeli nasıl düşünür, sohbetten ajana geçiş ve bir uygulamanın bir ajan ekibiyle 24 günde nasıl yapıldığı.

Sunumu açmak için `index.html` dosyasını Chrome veya Edge ile açın. Tek dosyadır, internet gerektirmez.
